## Changes Summary

### New Utilities (`packages/sdk/src/lib/stringUtils.ts`)
1. **toSnakeCase(input)** - Converts attribute IDs to canonical snake_case format
   - Replaces dots with underscores (`legacy.sku` → `legacy_sku`)
   - Converts camelCase (`productId` → `product_id`)
   - Handles hyphens, spaces, special characters
   - Collapses multiple underscores

2. **normalizeDataType(dataType)** - Maps data types to canonical forms
   - `text`, `longtext`, `varchar` → `string`
   - `select`, `dropdown` → `enum`
   - `multiSelect`, `list` → `array`
   - `money`, `price`, `currency` → `number`
   - `bool`, `yesno`, `checkbox` → `boolean`

3. **detectCollisions(ids)** - Finds IDs that would collide after snake_case conversion

### Updated Task (`packages/api/src/tasks/syncAttributeRegistry.ts`)
- **Collision Detection**: Aborts if two IDs map to same canonical form
- **No Fallback**: Aborts if registry not found (no product-derived fallback per LP-2.1.6)
- **Dry-run Mode**: Default behavior; use `--apply` to write changes
- **New Fields**:
  - `canonical: true` - Marks document as canonical
  - `definition_version: "1.0.3"` - Registry version
  - `source: "repo"` - Source of truth
  - `original_id` - Original attribute ID from registry
  - `aliases` - Array of alternative IDs (if any)
