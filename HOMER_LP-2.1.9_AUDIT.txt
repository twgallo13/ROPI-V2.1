API ENDPOINTS
================================================================================

POST /api/admin/exports/dry-run
  Purpose: Preview export with sample data
  Request Body:
    {
      "site": "ropi-web",      // optional
      "limit": 10,             // sample size (default: 10)
      "includeMeta": true      // include _meta columns
    }
  Response:
    {
      "success": true,
      "timestamp": "ISO-8601",
      "summary": { ... },
      "sampleCsv": "MPN,SKU,...",
      "columnHeaders": ["MPN", "SKU", ...],
      "attributesIncluded": ["gender", ...],
      "attributesExcluded": ["internal_notes", ...]
    }

POST /api/admin/exports
  Purpose: Run full export with pagination
  Request Body:
    {
      "site": "ropi-web",
      "includeMeta": true,
      "batchSize": 1000
    }
  Response:
    {
      "success": true,
      "csvContent": "MPN,SKU,...",
      "summary": { ... },
      "filePaths": ["storage/path/to/export.csv"]  // if saved
    }
  Error Condition: Blocks if >1% or >1000 unknown_export_value errors

GET /api/admin/exports/preview
  Purpose: Get column headers and attribute info
  Response:
    {
      "success": true,
      "columnHeaders": ["MPN", "SKU", ...],
      "attributes": [{ name, data_type, display_name }],
      "columnCount": 42
    }

================================================================================
CRITICAL BEHAVIORS
================================================================================

1. MPN as Primary Key
   - MPN is always the first column in exports
   - Products without MPN are skipped with missing_mpn error code
   - SKU column follows MPN (aggregates all variant SKUs)

2. Export Flag Enforcement
   - Only attributes with export: true are included
   - Attributes with export: false or export: undefined are excluded
   - Summary reports attributesIncluded and attributesExcluded

3. Canonical Value Mapping
   - Enum values matched against allowed_values (case-insensitive)
   - If exact match found, canonical value used
   - If value in synonyms map, mapped to canonical value
   - Unknown values produce unknown_export_value warning

4. Export Readiness
   - Checks all attributes where required_for_export: true
   - Product marked exportReady: true only if all required attrs present
   - Summary reports exportReadyCount vs notExportReadyCount

5. _meta Provenance Columns
   - When includeMeta: true, adds {attr}_meta columns
   - JSON structure: { actor, source, ts, definition_version }
   - Enables downstream audit/lineage tracking

6. MultiSelect Handling
   - Array values joined with pipe delimiter (|)
   - Each value in array mapped to canonical form
   - Example: ["Suede", "Leather"] → "Suede|Leather"

7. Error Blocking
   - Full export blocked if unknown_export_value errors exceed threshold
   - Threshold: >1% of total values OR >1000 absolute count
   - Prevents polluting downstream with non-canonical data
