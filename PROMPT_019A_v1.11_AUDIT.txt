## Technical Details

### YAML Heredoc Issue Explained
In YAML, a `run: |` block expects all content to be indented relative to the `run:` key. Bash heredocs (`<<'EOF'`) require their terminator to be at column 0, which conflicts with YAML's indentation rules.

**Why it broke**:
```yaml
run: |
  python3 - <<'PY'
import sys, json  # ← Column 0! YAML thinks this is a new root key
PY
```

**Why it works now**:
```yaml
run: |
  python3 -c "import sys,json; json.load(open('/tmp/sa.json'))"  # ← All indented
```
