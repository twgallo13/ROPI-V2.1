================================================================================
LESSONS LEARNED
================================================================================

1. **Secret Format Handling**: GitHub Secrets can have various formats depending
   on how they're entered (UI paste, CLI, with/without encoding). The very robust
   decode handles all cases.

2. **CRLF Issues**: Windows copy-paste introduces CRLF that breaks base64 decode.
   The `tr -d '\r\n'` solution is essential.

3. **Validation Before Use**: Always validate JSON structure before using service
   account keys. Python3 json.load() provides better error messages than jq.

4. **Diagnostic Steps**: Temporary diagnostic steps were invaluable for debugging
   but should be removed once the root cause is fixed.

5. **Gcloud Configuration**: Explicit `gcloud config set account` and
   `gcloud config set project` ensure consistent behavior.
