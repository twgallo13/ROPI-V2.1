ROBUST DECODE PATCH SUMMARY
================================================================================

Patch Version: PROMPT_019A_v1.8
Commit: 9ccc14c → fc94e0a (after merge conflict resolution)
Merged To: aoss-main (commit 3067445)

Key Improvements:
1. Auto-detection: Raw JSON or base64 input
2. CRLF handling: tr -d '\r\n' before base64 decode
3. JSON validation: jq -e . /tmp/sa.json
4. Error preview: head -c 400 on validation failure
5. Better logging: Clear success/failure messages
6. Consistent naming: GCP_SA_KEY_BASE64 (not FIREBASE_SA_KEY)

Before (Old Logic):
```bash
echo "${SA_B64}" | base64 --decode > /tmp/sa.json
```
Problems: CRLF breaks base64, no validation, poor errors

After (Robust Logic):
```bash
SA_B64="${GCP_SA_KEY_BASE64:-}"
[ -z "$SA_B64" ] && exit 1

firstchar="$(printf '%s' "$SA_B64" | head -c 1)"
if [ "$firstchar" = "{" ] || [ "$firstchar" = "[" ]; then
  printf '%s' "$SA_B64" > /tmp/sa.json
else
  printf '%s' "$SA_B64" | tr -d '\r\n' | base64 --decode > /tmp/sa.json
fi

jq -e . /tmp/sa.json || { head -c 400 /tmp/sa.json; exit 1; }
chmod 600 /tmp/sa.json
```

Benefits:
- Handles Windows copy-paste (CRLF)
- Accepts raw JSON fallback
- Validates before use
- Clear error diagnostics
- Idempotent (safe to re-run)
