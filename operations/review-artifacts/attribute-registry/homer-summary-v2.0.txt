## CODE CHANGES

### src/utils/attributeRegistry.ts (NEW)
- getAttributeRegistry(): Fetches settings/attributes/keys/* from Firestore with 5-min cache
- getImportableAttributes(): Filters to attributes with non-empty importerColumns
- buildHeaderToPathMap(): Creates case-insensitive CSV header → canonical path map
- resolveHeaderToPath(): Resolves single CSV header to canonical path
- clearRegistryCache(), getRegistryStatus(): Cache management utilities

### src/components/MappingReview.tsx (REFACTORED)
- Added useEffect hook to load registry on mount via getImportableAttributes()
- Replaced hardcoded <option> elements (lines 78-108) with dynamic optgroups grouped by category
- Added loading/error states for registry fetch failures
- Added search filter for attribute dropdown navigation
- Display format: "Label (canonicalPath)" with required marker (*)
- Excluded technical.variantCount automatically (getImportableAttributes filters empty importerColumns)

### src/utils/csvParser.ts (ENHANCED)
- Added parseCSVAsync(): Async version with registry support
- Created autoMapHeaderAsync(): Priority 0 = registry lookup, Priority 1-3 = static synonyms fallback
- Kept parseCSV() synchronous for backwards compatibility (static synonyms only)
- Registry mapping takes precedence over hardcoded HEADER_SYNONYMS
- Fallback to static synonyms if registry unavailable

### src/pages/ImportPage.tsx (UPDATED)
- Changed parseCSV() call to parseCSVAsync() in handleFileSelect()
- Import now uses registry-driven auto-mapping by default

### src/config/appConfig.ts (NEW)
- Feature flag: ENABLE_DYNAMIC_IMPORTER = true (can be disabled for rollback)
- ENABLE_REGISTRY_CACHE = true (5-minute TTL)
- Environment variable overrides supported via VITE_FEATURE_* env vars

- Case-insensitive header matching: "Group", "group", "GROUP" all resolve to descriptive.gender
- Duplicate headers are ignored (only first occurrence mapped)
- Registry failure falls back to static HEADER_SYNONYMS gracefully
- Option display format: "Label (canonicalPath)" for clarity
