## Summary

Implemented attribute grouping, vocab display, and product-value preview in the Attributes Command Center to make the ACC less confusing and more human-intuitive.

### Key Features

1. **Canonical Path Grouping**
   - Attributes with same canonical path grouped into one row
   - Expandable variants showing different labels/aliases
   - Reduces perceived "duplicate attributes" confusion

2. **Source Badges**
   - Core, Vendor, Legacy, AI, Deprecated tags
   - Clear visual indication of attribute sources
   - Multiple tags for complex attributes

3. **Vocab Display**
   - Inline allowed-values shown as pills in Validation tab
   - Displays when `validation.allowedValues` present
   - Shows source reference (`allowedValuesRef`)

4. **Product-Value Preview**
   - Samples up to 500 product documents
   - Shows value distribution with counts and percentages
   - Helps understand real-world data usage

5. **Attach Vocab Helper**
   - Detects stable vocab sets (2-20 values, 60%+ coverage)
   - Provides UI hint to attach vocab reference
   - Placeholder for v3.4 full implementation

6. **Seeder Enhancement**
   - Denormalizes normalized values to `validation.allowedValues`
   - Safe, minimal changes (only adds, doesn't modify existing)
   - Backward compatible
