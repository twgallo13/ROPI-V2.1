**Branch:** feat/v3.3-sku-preview
**Status:** ✅ Ready for Review

## Summary

Added "Show sample SKUs" feature to Attribute Detail Drawer (Validation tab) that displays concrete product examples showing SKU, value, and raw field path for a canonical attribute.

## Changes Made

### Backend (Cloud Functions)

**File:** `functions/src/handlers/attributes.ts`
- Added `getValuePreview()` function
- Queries products collection for up to 50 docs (configurable limit)
- Navigates nested product structure using canonical path
- Returns array of samples with SKU, value, rawPath, docId

**File:** `functions/src/api/index.ts`
- Added route: `GET /api/attributes/value-preview?path=<canonicalPath>&limit=<number>`

### Frontend (Client)

**File:** `src/hooks/useAttributeValuePreview.ts` (NEW)
- React hook for fetching value preview
- Manages loading, samples, and error states
- Returns `{ samples, loading, error, load }` interface

**File:** `src/pages/settings/components/AttributeDetailDrawer.tsx`
- Import added: `useAttributeValuePreview` hook
- Hook instantiated with `formData.canonicalPath`
- UI section added below "Current Product Values":
  - "Show sample SKUs" button
  - Sample cards showing SKU, Value, Raw Path
  - Error handling display
  - Loading state
