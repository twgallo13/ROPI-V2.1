# Feature 4: Permissions UX Improvements
**Branch:** `chore/v3.3-permissions-ux`
**Status:** ✅ Complete

## Implementation Summary

Improved UX for non-editable users in the Attribute Command Center by:
1. **Role display in ACC header** - Users can always see their role (Viewer/Editor/Administrator)
2. **Friendly permission modal** - Replace generic alert() with informative modal showing:
   - Current role vs required role
   - How to request access from admin
   - Clear call-to-action button

## Changes Made

### 1. Created `PermissionRequestModal` Component
**File:** `src/pages/settings/components/PermissionRequestModal.tsx` (NEW)
- **Purpose:** Friendly modal for permission denial
- **Features:**
  - Shows current role badge vs required role
  - Instructions: "Contact admin → Request role → Refresh"
  - Clean UI with lock icon and "Got it" button
  - Accepts `currentRole` and `requiredRole` props

### 2. Updated `AttributesCommandCenter.tsx`
**File:** `src/pages/settings/AttributesCommandCenter.tsx`
- **Added role display in header:**
  - Right-aligned badge showing "Viewer", "Editor", or "Administrator"
  - Glass-morphism design (white/20 backdrop-blur)
  - Visible at all times for user awareness

### 3. Updated `AttributeDetailDrawer.tsx`
**File:** `src/pages/settings/components/AttributeDetailDrawer.tsx`
- **Import PermissionRequestModal component**
- **Import useAuth hook** to get current role
- **Added state:** `showPermissionModal` (boolean)
- **Modified handleSave():**
  - If `!isEditable`, opens modal instead of silently returning
  - User sees friendly message about needing Editor role
- **Renders PermissionRequestModal** in component tree

### 4. Fixed Test Mocks
**File:** `src/__tests__/AttributeDetailDrawer.suggest-visibility.test.tsx`
- **Added mock for AuthContext:**
  - Returns role: 'editor', user: mock data, loading: false
  - Fixes "useAuth must be used within AuthProvider" test error

## Testing Instructions

### Manual Testing

1. **As Viewer:**
   - Open ACC → See "Your Role: Viewer" badge in header
   - Click on an attribute → Try to click "Save"
   - Verify modal appears with permission request instructions

2. **As Editor/Admin:**
   - Open ACC → See "Your Role: Editor" or "Administrator" badge
   - Click on an attribute → Click "Save"
   - Verify save works normally (no modal)

3. **Modal Interaction:**
   - Click "Save" as viewer → Modal opens
   - Click overlay or "Got it" → Modal closes
   - Verify modal shows correct current role and required role
