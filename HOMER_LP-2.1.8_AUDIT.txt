## VALIDATION FEATURES

### MPN Required
- Error code: mpn_required
- All rows must have non-empty MPN column
- Case-insensitive column matching (MPN, mpn)

### Data Type Validation
- string: Pass-through
- number: Parses numeric strings, error on invalid
- boolean: Accepts true/false, yes/no, 1/0
- enum: Validates against allowed_values
- multiSelect: Parses pipe|comma delimited, validates each value
- date: Validates ISO 8601 format
- currency: Parses numeric with optional currency symbol
- json: Validates JSON string parsing

### Enum/MultiSelect Validation
- Validates against allowed_values array
- Supports synonyms mapping from attribute definition
- Case-insensitive matching
- Non-strict: Warns on unknown values
- Strict (import_strict: true): Errors on unknown values

### Import Flag Enforcement
- Error code: import_disabled
- Rejects columns mapped to attributes with import: false

### Import Required Enforcement
- Error code: import_required
- Errors when import_required: true attributes are missing from row

### Per-Row Diagnostics
- row: Row number (1-indexed)
- status: 'valid' | 'warning' | 'invalid'
- normalizedValues: Transformed values after validation
- errors: Array of {code, column, message, value}
- warnings: Array of {code, column, message, value}
