- URL changes sync to active tab via useEffect
- Browser back/forward navigation supported

Product ID Handling:
- ID from URL params (:id)
- useProduct hook attempts to load from localStorage
- Falls back to mock data if not found
- Default ID: 123 if no ID in URL

================================================================================
DATA PERSISTENCE
================================================================================

localStorage Keys:
------------------
aoss:product:<id> - Product data JSON

Storage Strategy:
- Read on mount from localStorage or fall back to mock
- Write on every mutation (updateField, addObservation, etc.)
- Auto-recalculate export readiness on save

Data Mutations:
- updateField(path, value) - Update nested field via dot notation
- addObservation(newObs) - Add observation with timestamp
- resolveObservation(id) - Toggle observation to resolved
- applySuggestion(id) - Update field + mark suggestion applied
- ignoreSuggestion(id) - Mark suggestion ignored

Export Readiness Calculation:
- Triggered on every saveProduct call
- Iterates through all websites
- Checks required fields per website
- Calculates per-website score (0-100)
- Averages scores for overall readiness
