C. Observations Service (observations.ts)
------------------------------------------
Location: packages/web/src/services/observations.ts

Functions:
1. listObservations(productId: string): Promise<Observation[]>
   - Loads observations for a product
   - Uses Firestore if available, otherwise localStorage
   - Sorts by creation date (newest first)
   - Handles Firestore errors gracefully

2. addObservation(input: CreateObservationInput, imageFiles?: File[]): Promise<Observation>
   - Creates new observation
   - Uploads images to Storage if available
   - Falls back to data URLs if Storage unavailable
   - Persists to Firestore or localStorage
   - Returns created observation with generated ID

3. resolveObservation(observationId: string, productId: string, resolvedBy: ObservationCreator): Promise<void>
   - Marks observation as resolved
   - Updates status, resolvedBy, and resolvedAt
   - Works with both Firestore and localStorage

4. uploadImage(productId: string, file: File): Promise<string>
   - Uploads image to Firebase Storage
   - Path: gs://<bucket>/observations/<productId>/<timestamp>_<filename>
   - Returns download URL if successful
   - Falls back to data URL if Storage unavailable

5. listenToObservations(productId: string, onUpdate: (obs: Observation[]) => void): Unsubscribe
   - Sets up real-time listener for observations
   - Automatically updates when Firestore documents change
   - Falls back to one-time load from localStorage
   - Returns unsubscribe function

6. syncLocalToFirestore(productId: string): Promise<{ success: number, failed: number }>
   - Syncs localStorage observations to Firestore
   - Identifies local-only observations (id starts with "local_")
   - Uploads each to Firestore
   - Updates localStorage with Firestore IDs
   - Returns count of successful/failed syncs

Storage Logic:
- localStorage key pattern: "aoss:observations:<productId>"
- Firestore collection: "observations"
- Storage path: "observations/<productId>/<timestamp>_<filename>"
- Automatic sorting by creation date (newest first)
- Graceful error handling with console warnings

G. Firestore Indexes (firestore.indexes.json)
----------------------------------------------
Location: firestore.indexes.json (root directory)

Status: ⚠️ NOT DEPLOYED (PR only, as instructed)

Indexes:
1. productId + createdAt (descending)
   - Used by: listObservations()
   - Query: where('productId', '==', X) orderBy('createdAt', 'desc')

2. productId + status + createdAt (descending)
   - Used for filtered queries by status
   - Query: where('productId', '==', X).where('status', '==', Y).orderBy('createdAt', 'desc')

3. status + severity + createdAt (descending)
   - Used for cross-product filtering
   - Query: where('status', '==', X).where('severity', '==', Y).orderBy('createdAt', 'desc')

Note: Firebase may auto-generate these indexes when queries are first run.
Explicit indexes here ensure optimal performance.

⚠️ WARNING: Do not deploy these indexes without testing queries first.
