# Homer — Firebase Attributes Cleanup Evidence

This folder captures before/after Firestore snapshots and deletion logs for the cleanup making `settings/attributes/keys` the only source of truth.

Contents will be generated by scripts/cleanup-legacy-attributes.mjs:
- before.attributes.tree.json — Subcollections + counts under settings/attributes before cleanup
- dryrun.after.attributes.tree.json — After snapshot for dry-run
- after.attributes.tree.json — After snapshot for real run
- delete.results.json — Deletion results (attempted, deleted)
- dryrun.delete.results.json — Deletion plan (no writes performed)
- legacy.hits.json — Any legacy-named docs discovered in non-preserved subcollections

How to run (dry-run first):

```bash
export PROJECT_ID=ropi-bccee
# one of: GOOGLE_APPLICATION_CREDENTIALS=/path/to/sa.json OR FIREBASE_SERVICE_ACCOUNT_JSON=<json or base64>
node scripts/cleanup-legacy-attributes.mjs \
  --project "$PROJECT_ID" \
  --preserve keys,audit \
  --dry-run \
  --out inventory/homer-attr-cleanup-2026-01-09/evidence
```

Apply for real (preserving keys,audit):

```bash
node scripts/cleanup-legacy-attributes.mjs \
  --project "$PROJECT_ID" \
  --preserve keys,audit \
  --out inventory/homer-attr-cleanup-2026-01-09/evidence
```

Notes
- We default to preserving `keys` and `audit`. If you truly want to remove audit, pass `--preserve keys`.
- The Product UI already reads attribute definitions via admin API from `settings/attributes/keys`.
