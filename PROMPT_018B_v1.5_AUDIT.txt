OBJECTIVE
================================================================================
Fix the Observations panel responsiveness issue where the Add Observation button
was being clipped/hidden due to overflow: hidden and fixed heights. Make the
panel scrollable with the Add button positioned sticky at the bottom so it
remains visible when scrolling through observations.

================================================================================
PROBLEM SUMMARY
================================================================================
On staging (https://ropi-aoss-staging.web.app/):
- Add Observation button was clipped/hidden in the Observations sidebar
- Panel used `overflow: hidden` which prevented proper scrolling
- Fixed heights on panels prevented content from being accessible
- Users could not reliably access the Add button when multiple observations
  were present

Root Cause:
- .product-panel had `overflow: hidden` without flex layout
- .product-panel-content lacked scrolling behavior
- .panel-add-button was positioned statically, could scroll out of view

================================================================================
SOLUTION IMPLEMENTED
================================================================================

Applied CSS changes to two files:

1. packages/web/src/pages/ProductEditorPage.css
   - Modified .product-panel class
   - Modified .product-panel-content class

2. packages/web/src/components/product/ObservationsPanel.css
   - Modified .panel-add-button class

================================================================================
DETAILED CHANGES
================================================================================

File: packages/web/src/pages/ProductEditorPage.css
-------------------------------------------------------

Change 1: .product-panel (lines ~198-203)
------------------------------------------
BEFORE:
  .product-panel {
    background-color: var(--color-background);
    border: 1px solid var(--color-border);
    border-radius: 8px;
    overflow: hidden;
  }

AFTER:
  .product-panel {
    background-color: var(--color-background);
    border: 1px solid var(--color-border);
    border-radius: 8px;
    /* Make panel a column flex container so header/content/footer can size correctly */
    display: flex;
    flex-direction: column;
    /* Allow children to handle scrolling instead of clipping */
    overflow: visible;
  }

Rationale:
  - display: flex + flex-direction: column enables proper sizing of child elements
  - overflow: visible removes clipping behavior, allows children to manage scroll
  - Flex layout enables header/content/footer to size independently

Change 2: .product-panel-content (lines ~233-235)
--------------------------------------------------
BEFORE:
  .product-panel-content {
    padding: var(--spacing-md);
  }

AFTER:
  .product-panel-content {
    padding: var(--spacing-md);
    /* Allow content to grow/shrink and scroll inside the panel */
    flex: 1 1 auto;
    min-height: 0; /* enables proper flexbox scrolling behavior */
    overflow: auto;
  }

Rationale:
  - flex: 1 1 auto allows content to fill available space and shrink when needed
  - min-height: 0 is critical for flexbox children to enable scrolling
  - overflow: auto adds scrollbars when content exceeds available height

File: packages/web/src/components/product/ObservationsPanel.css
----------------------------------------------------------------

Change 3: .panel-add-button (lines ~119-129)
---------------------------------------------
BEFORE:
  .panel-add-button {
    width: 100%;
    padding: 0.75rem;
    background: var(--color-primary);
    color: white;
    border: none;
    border-radius: 6px;
    font-size: var(--font-size-sm);
    font-weight: 500;
    cursor: pointer;
    transition: all 0.2s;
    margin-top: 0.75rem;
  }

AFTER:
  .panel-add-button {
    width: 100%;
    padding: 0.75rem;
    background: var(--color-primary);
    color: white;
    border: none;
    border-radius: 6px;
    font-size: var(--font-size-sm);
    font-weight: 500;
    cursor: pointer;
    transition: all 0.2s;
    margin-top: 0.75rem;
    /* Ensure Add button remains visible within the panel content (stick to bottom) */
    position: sticky;
    bottom: 1rem;
    z-index: 2;
  }

Rationale:
  - position: sticky makes button stay in view when scrolling
  - bottom: 1rem anchors button 1rem from bottom of scrollable area
  - z-index: 2 ensures button appears above other panel content

TECHNICAL DETAILS
================================================================================

CSS Properties Used:

display: flex
  - Browser support: All modern browsers (IE 10+)
  - Creates flex formatting context for children

flex-direction: column
  - Standard flexbox property
  - Stacks children vertically

overflow: visible / auto
  - Standard CSS properties
  - `visible` on parent, `auto` on scrollable child

flex: 1 1 auto
  - Shorthand for flex-grow, flex-shrink, flex-basis
  - Allows element to fill available space

min-height: 0
  - Critical for flexbox scrolling behavior
  - Overrides default min-content behavior

position: sticky
  - Browser support: All modern browsers (Safari 13+, Chrome 56+, Firefox 59+)
  - Creates sticky positioning context within scrollable container

z-index: 2
  - Ensures button appears above other panel content
  - Low value to avoid conflicts with modals (z-index: 1000)

Browser Compatibility:
  - All changes use well-supported CSS properties
  - No experimental features
  - No vendor prefixes required
  - Tested in: Chrome, Firefox, Safari, Edge (all modern versions)
