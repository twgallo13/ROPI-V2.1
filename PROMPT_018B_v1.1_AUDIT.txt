OBJECTIVE
================================================================================

Implement Option A fix for PR preview deploy workflow to ensure reliable 
preview channel deployments on Firebase Hosting.

PROBLEM STATEMENT:
- CI preview workflow was failing with "Directory 'packages/web/dist' for 
  Hosting does not exist."
- Root cause: Preview deploy used repository firebase.json which points to 
  packages/web/dist, but the workflow prepares public/ folder instead
- Build step was soft-failing (continuing on error), hiding real build issues

================================================================================
IMPLEMENTATION
================================================================================

PR DETAILS:
- Branch: fix/preview-deploy-option-a_PROMPT_018B_v1.1
- PR #164: https://github.com/twgallo13/ROPI-V2.1/pull/164
- Base branch: aoss-main
- Commit: 8933328

FILES CHANGED:
- .github/workflows/deploy-preview.yml

CHANGES APPLIED:

1. Build Step Enhancement:
   - Renamed from "Build (if web exists)" to "Build (web)"
   - Changed soft-fail (|| echo) to hard-fail (|| { echo "::error::"; exit 1; })
   - Added comprehensive output directory logging:
     * Lists packages/web
     * Checks packages/web/dist, build, out, .next directories
     * Shows ls -la output for existing directories
   - Purpose: Surface real build failures immediately, provide diagnostic info

2. Deploy Step Fix:
   - Creates temporary firebase_preview.json in workflow
   - Config points "public" field to "public" folder (prepared by workflow)
   - Config includes "aoss-staging" target with SPA rewrites
   - Uses --config firebase_preview.json flag in firebase CLI deploy command
   - Purpose: Deploy from prepared public/ folder instead of expecting 
     packages/web/dist

TECHNICAL APPROACH:
- Minimal, non-invasive change
- Does NOT modify repository firebase.json (canonical config untouched)
- Creates ephemeral firebase_preview.json only during CI workflow execution
- Safe short-term unblock for PR preview deploys
