#### 3. requireAdmin middleware (lines 171-211)
```typescript
export async function requireAdmin(
  req: ExpressRequest,
  res: ExpressResponse,
  next: () => void
): Promise<void> {
  const auth = await verifyAuthToken(req);
  
  if (!auth) {
    res.status(401).json({
      error: 'INVALID_AUTH_TOKEN',
      reason: 'missing_or_invalid_token',
      message: 'Valid authentication token required...'
    });
    return;
  }
  
  const hasAdminClaim = isAdmin(auth);
  const hasAdminAllowlist = hasAdminClaim ? false : await isAdminAllowlisted(auth.email);

  if (!hasAdminClaim && !hasAdminAllowlist) {
    res.status(403).json({
      error: 'Forbidden',
      message: 'Admin role required for this operation',
    });
    return;
  }
  
  (req as AuthenticatedRequest).auth = auth;
  next();
}
```

### Token Sources (Priority Order)
1. `Authorization: Bearer <token>` header (preferred)
2. `__session` cookie (Firebase Hosting convention)

### Admin Check Logic
1. Check `auth.role` via `isAdminRole()` function
2. Check `auth.roles[]` array includes 'admin'
3. Fallback to Firestore allow-list (`metadata/admins` document)

### Error Responses
| HTTP | Error Code | Reason | Cause |
|------|------------|--------|-------|
| 401 | INVALID_AUTH_TOKEN | missing_or_invalid_token | No token or token verification failed |
| 403 | Forbidden | - | Token valid but no admin role |

### Root Cause Analysis

The code reads `firebase_token` from localStorage, but this key is **never written**.
Result: `localStorage.getItem('firebase_token')` always returns `null`.
With the `|| ''` fallback, this becomes an empty string.
The Authorization header becomes: `Bearer ` (no token).
Server receives empty Bearer token → 401 Unauthorized.

### Fix Required
Replace all `localStorage.getItem('firebase_token')` usages with proper
