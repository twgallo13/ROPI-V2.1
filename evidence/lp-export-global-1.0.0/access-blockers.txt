**Resource:** settings/{tenant}/exportSettings/config  
**Resource:** settings/{tenant}/completionRules/config  
**Blocker:** No Firestore write permissions in dev environment  
**Required IAM Permissions:**
- `firestore.documents.create`
- `firestore.documents.update`
- Read access to verify writes

**Required for:**
- Phase 2: Create exportSettings config document with mode field
- Phase 4: Add product-classification segment to completionRules
- All phases: Feature flag toggles for testing and rollback

**Impact:** Cannot execute migration scripts (create_export_config.js, apply_classification_segment.js)

**Workaround:** Use Firebase Console UI to manually create/update Firestore documents:
1. Navigate to Firestore → settings/{tenant}/exportSettings/config
2. Manually add field: `mode: "SITE_SCOPED"` (default)
3. For Phase 4: Navigate to completionRules/config → Add segment object to `segments[]` array
