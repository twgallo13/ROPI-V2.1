VERY ROBUST DECODE PATCH DETAILS
================================================================================

File: .github/workflows/set-admin-claim.yml
Step: "Decode service account key (very robust)"
Version: PROMPT_019A_v1.10

Key Logic Flow:
1. Check secret not empty: [ -z "$SA_RAW" ] && exit 1
2. Trim whitespace: sed -e 's/^[[:space:]]*//' -e 's/[[:space:]]*$//'
3. Detect format:
   a. If starts/ends with ": Quoted JSON → python3 unescape
   b. Else if starts with { or [: Raw JSON → direct write
   c. Else: Base64 → tr -d '\r\n' | base64 --decode
4. Validate JSON:
   a. Try python3 json.load()
   b. Fallback to jq if python not present
5. Set permissions: chmod 600 /tmp/sa.json
6. Success message: "Decoded service account JSON present at /tmp/sa.json (validated)"

Supported Secret Formats:
✅ Clean base64 (single line)
✅ Base64 with Windows CRLF
✅ Raw JSON (multi-line or single-line)
✅ Quoted JSON string (escaped quotes/newlines)
✅ Whitespace-padded secrets
✅ Mixed formats from different entry methods

Error Handling:
- Base64 decode failure: Shows first 160 chars + error output
- JSON validation failure: Shows first 400 chars of decoded content
- Empty secret: Clear error message
- Python fallback: Automatic jq install if python unavailable

Benefits Over Previous Versions:
v1.8 (PR #176):
- Only handled raw JSON or base64
- No whitespace trimming
- No quoted JSON support
- Basic CRLF handling

v1.10 (PR #177):
- ✅ Whitespace trimming
- ✅ Quoted JSON unescape
- ✅ Enhanced CRLF handling
- ✅ Better validation (python3 primary)
- ✅ Comprehensive error diagnostics
- ✅ All secret format support
