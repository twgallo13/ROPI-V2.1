## Technical Notes

### Status Logic
- `ok`: Firestore reachable, has attributes, can load snapshot
- `degraded`: Formerly for missing SDK registry (now informational)
- `error`: Firestore unreachable or empty

### SDK Registry Deprecation
The SDK registry file (`attributeRegistry.json`) is deprecated. Its absence is now informational only - Firestore is authoritative at runtime. This aligns with PR1 (registry bridge) which made Firestore the single source of truth.

### API Routing Note
Direct function URL requires `/api/api/...` path (double api prefix). The hosted URL (`ropi-bccee.web.app`) uses single `/api/...` prefix due to Firebase hosting rewrites. The verify script defaults to the hosted URL.
