LESSONS LEARNED
===============

1. IAM Permissions vs Authentication
   - v0.4.4 identified: Authentication ≠ Authorization
   - vNEXT confirmed: Granting permissions resolves deploy failures
   - Takeaway: Always verify both auth AND permissions

2. Test-Driven Validation
   - Creating test PR (#152) provided clean validation
   - Isolated testing prevented production impact
   - Takeaway: Use synthetic tests for workflow validation

3. continue-on-error for Gradual Rollout
   - v0.4.4: Used to unblock CI during permission issues
   - vNEXT: Removed after validation
   - Takeaway: Temporary flags enable safe incremental fixes

4. URL Extraction from Firebase JSON
   - Firebase channel deploy returns nested JSON structure
   - Correct path: .result["<target>"].url
   - Incorrect path: .result[0].site
   - Takeaway: Validate jq paths against actual JSON structure

5. Fork Security Model
   - workflow_dispatch requires workflow:write permission
   - GITHUB_TOKEN from fork PRs has limited permissions
   - Takeaway: Design workflows for fork compatibility
