ROOT CAUSE ANALYSIS
================================================================================

**Why Users Reported Old Bundle**:

**Theory 1: Browser Cache (Most Likely)**
- User visited ropi-aoss-staging BEFORE PROMPT_017 deployment
- Browser cached the old HTML with `index-CrgUsCf2.js` reference
- Cache-control: max-age=3600 (1 hour validity)
- User did normal refresh (F5) which respects cache headers
- Browser served cached HTML, loaded old bundle
- Old bundle had dummy config → Firebase init failed

**Theory 2: CDN Edge Lag**
- PROMPT_017 deployed to Firebase Hosting
- Firebase invalidates CDN, but propagation takes time
- Some CDN edges (different geographic regions) still served old content
- User connected to an edge that hadn't updated yet

**Theory 3: DNS Propagation** (Unlikely)
- Less likely since both URLs resolve to same Firebase infrastructure

**Why Redeploy Fixes It**:
1. Creates new Firebase Hosting version
2. Firebase signals all CDN edges to invalidate cache
3. CDN immediately starts serving fresh content (x-cache: MISS)
4. After ~5-10 minutes, all edges worldwide have fresh content
5. Users who do ANY refresh (even F5) will get new HTML after cache TTL expires
6. Users who do hard refresh (Ctrl+F5) bypass cache immediately
